# Dmikusa Tap

## How do I install these formulae?

`brew install dmikusa/tap/<formula>`

Or `brew tap dmikusa/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dmikusa/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
